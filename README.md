# Purna Kishore Devarasetty

Personal portfolio for Purna Kishore Devarasetty, an IT Desktop Engineer based in Hyderabad, India.

**Live website:** [purnakishoredevarasetty-hue.github.io/kishore-portfolio](https://purnakishoredevarasetty-hue.github.io/kishore-portfolio/)

## About

The portfolio highlights experience in endpoint management, cloud infrastructure, IT support, and security, along with career history, education, technical skills, and contact information.

## Features

- Responsive design for desktop and mobile
- Interactive light and dark themes
- Career timeline, skills, education, and language sections
- Email and LinkedIn links
- Downloadable resume

## Files

- `index.html` — standalone portfolio website, including its styles and JavaScript
- `kishore-resume.pdf` — downloadable resume

## GitHub Pages

The site is published with GitHub Pages from the `main` branch, using the repository root as the publishing source. To publish changes, commit them to `main`; GitHub Pages will deploy the updated site.
